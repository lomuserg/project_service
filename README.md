# Project Service — публикация событий для системы достижений

В этом микросервисе реализована отправка событий `TeamEvent` в Redis Pub/Sub для последующей обработки системой достижений.

## Реализовано:

- **Redis Pub/Sub интеграция**
  - Добавлена конфигурация Redis-топика `team_channel`.
  - Реализован RedisPublisher для событий `TeamEvent` (Spring Data Redis).
  - Настроена сериализация событий в JSON.

- 📢 **Публикация событий создания команды**
  - При создании команды в проекте автоматически публикуется событие:
    - `authorId`
    - `projectId`
    - `teamId`

- 🧪 **Тестирование**
  - Покрытие unit-тестами публикации событий.

## 📚 Технологии
- Spring Boot
- Spring Data Redis
- Redis
- PostgreSQL
- JUnit, Mockito
